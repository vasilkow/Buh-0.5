# YouTube Checker Bot

Telegram-бот для проверки статистики YouTube-каналов и видео на признаки теневого бана.

## Возможности

- 📊 Статистика канала (подписчики, просмотры, видео)
- 🎬 Статистика видео (просмотры, лайки, комментарии)
- 📈 Динамика просмотров (история изменений)
- 🔍 Быстрая проверка на признаки проблем
- 🔬 Комплексная проверка с анализом:
  - Приватность видео
  - Индексация в поиске YouTube
  - Соотношение просмотров к подписчикам
  - Скорость набора просмотров
  - Спам-признаки в заголовке/описании
  - Возраст канала
  - Сравнение с другими видео канала
  - Вовлечённость (комментарии/просмотры)
- 📊 Сравнение нескольких видео
- 📅 Ежедневный мониторинг (автоматические отчёты в 9:00)

## Команды бота

- `/start` — справка
- `/channel @username` — статистика канала
- `/video ссылка` — статистика видео
- `/history VIDEO_ID` — динамика просмотров
- `/check VIDEO_ID` — быстрая проверка
- `/deepcheck VIDEO_ID ключ1,ключ2` — полная проверка
- `/compare ID1,ID2,ID3` — сравнение видео
- `/monitor VIDEO_ID` — добавить в мониторинг
- `/unmonitor VIDEO_ID` — убрать из мониторинга

## Установка

### 1. Получи API-ключи

**Telegram Bot Token:**
1. Открой @BotFather в Telegram
2. Отправь `/newbot`
3. Следуй инструкциям
4. Скопируй токен

**YouTube Data API Key:**
1. Перейди на https://console.cloud.google.com
2. Создай новый проект
3. Включи YouTube Data API v3
4. Создай API-ключ в разделе Credentials
5. Скопируй ключ

### 2. Деплой на Railway

1. Зарегистрируйся на https://railway.app
2. Нажми "New Project" → "Deploy from GitHub repo"
3. Выбери свой репозиторий с ботом
4. Добавь переменные окружения:
   - `TELEGRAM_TOKEN` — токен от @BotFather
   - `YOUTUBE_API_KEY` — ключ YouTube API
5. Railway автоматически определит Python и запустит бота

### 3. Альтернатива: локальный запуск

```bash
# Установи зависимости
pip install -r requirements.txt

# Создай .env файл
echo "TELEGRAM_TOKEN=your_token_here" > .env
echo "YOUTUBE_API_KEY=your_youtube_key_here" >> .env

# Запусти бота
python bot.py
